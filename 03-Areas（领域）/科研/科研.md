# 科研

## ✨ 核心摘要

科研领域的长期入口。当前处于入门阶段，重点是把「找问题 → 读文献 → 提 Idea → 做实验 → 写论文/汇报」的方法论固化成可复用的流程，并用好习惯维持日常积累。

## 🧭 科研流程（TPIC）

> Topic → Problem → Idea → Concrete Work → Paper Writing → Submit

| 阶段 | 方法笔记 | 说明 |
| --- | --- | --- |
| Topic | [[如何找论文？]] | 从会议/期刊、种子论文、引用网络、作者与代码生态建立文献基础 |
| Problem | [[如何读论文？]]、[[如何想Idea？]] | 批判性阅读，从不足和 failure case 中找问题 |
| Idea | [[如何想Idea？]] | Problem-driven 为主，Method-driven 为辅 |
| Concrete Work | [[如何做科研？]] | 实验设计、结果分析与验证 |
| Paper / 汇报 | [[如何进行学术汇报]] | PPT 形式、内容选择与论文汇报框架 |
| 协作 | [[如何高效Meeting]] | 用 Meeting 暴露问题、推进工作 |
| 日常 | [[一些好的习惯]] | 学术输入、知识管理、实验/问题/想法记录 |
