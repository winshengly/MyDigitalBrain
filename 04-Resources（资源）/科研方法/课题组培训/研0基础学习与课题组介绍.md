# 研0基础学习与课题组介绍

> 课题组以机器人方向为主，涉及 ROS 编程和 Python 编程。入学前需要自行购买书籍或通过网络学习 ROS；遇到问题可以问张剑锋、黄诗博、施晨凡等师兄。
